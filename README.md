# Avadalabs

Small, focused, multilingual web tools for developers and video creators.

## Projects

### [JWT Secret Key Generator](https://jwtsecretkey.com)
Free developer tools for JWT signing secrets, running in the browser with the Web Crypto API: an HS256 / HS384 / HS512 secret generator, a JWT decoder, a high-entropy secret key generator, a UUID v4 generator, a Base64 / Base64URL encoder and decoder, and a hash generator. Includes guides on JWT secrets, algorithms and claims. Available in English, French, Spanish and Arabic.

- Website: https://jwtsecretkey.com
- Chrome extension: [JWT Secret Key Generator & Decoder](https://chromewebstore.google.com/detail/jwt-secret-key-generator/oipdllipioacgijdpogjdgakofhcbdof) — the same toolbox offline, with right-click shortcuts

### [ThumbnailFetch](https://thumbnailfetch.com)
View and download the public thumbnail or cover image of a YouTube, TikTok, Facebook or Instagram video, in the sizes the platform actually provides. Free, no account. Available in English, Arabic, French and Spanish.

- Website: https://thumbnailfetch.com
- Open data: [video-thumbnail-sizes](https://github.com/Avadalabs/video-thumbnail-sizes) — thumbnail and cover sizes for major video platforms, with official sources
